# carrear-kit

Marketplace de plugins de CarrEar.

## Plugins
- **carrear** 0.3.0 — kit de prueba de humo: `carrear-hola` (cascarón) y `carrear-instalar-humo` (mini-instalador según el onboarding de cliente: proyecto «Digital Brain», chat «📌 Instalador — CarrEar», carpeta «Digital Brain — <Nombre>» con 6 subcarpetas, «Digital Brain — Configuración», bitácora de pruebas aparte y tarea «⚙️ CarrEar — prueba de humo (diaria)»).

No contiene datos de ninguna persona.

## Instalar
En Claude Code: `/plugin install carrear --marketplace carrear-team/carrear-kit`
En claude.ai: Personalizar › Plugins › Añadir marketplace › `carrear-team/carrear-kit` › instalar «carrear».
